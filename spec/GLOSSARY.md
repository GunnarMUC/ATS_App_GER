# GLOSSARY.md

| Begriff | Bedeutung |
|---|---|
| Master-CV | Vollständiger, einmal gepflegter Lebenslauf |
| FactLock | Bestätigte JSON-Fakten inkl. Hash; Quelle der Wahrheit |
| Rollenfamilie / `role_family` | Grobe Klasse: ceo, coo, … |
| Rollensicht | Abbildung Master → Sicht für eine Rolle (Order, Hidden, Emphasis) |
| Rollenprofil | Gespeicherte Default-Sicht |
| AdaptationPlan | Jobspezifischer, bestätigbarer Umbau-Vorschlag |
| Ranker-Skelett | Deterministischer Plan ohne LLM (`lens_ranker.py`) |
| Bewerbung | Job + Plan + generierte Dokumente |
| strong / fast | Zwei konfigurierbare Ollama-Tags (dürfen identisch sein) |
| FactGuard | Deterministische Prüfung generiertes JSON vs. FactLock |
| ATS | Applicant Tracking System, hier DACH-Parser |
| Keyword-Binding | Zuordnung Stellenwort → existierender Bullet/Fakt |
| Alias | Synonym/Übersetzung/Kompositum-Variante eines Skills |
| Injection | Stellen- oder CV-Text, der das Modell umprogrammieren will |
| In-App-LLM | Ollama-Tag laut Settings — nicht SuperGrok |
| SuperGrok 4.6 | Coding-Modell in OpenCode |
| Ollama-Cloud-Tag | Modell, das Ollama ggf. weiterleitet; App blockt nicht, Banner erlaubt |
